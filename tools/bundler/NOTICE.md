# Bundler attribution

The three JavaScript helpers in this directory are copied from
[7GrandDadPGN/VapeBundler](https://github.com/7GrandDadPGN/VapeBundler),
the build tool used by the upstream Vape V4 project. The upstream package
declares the ISC license. `../build-dev.js` adapts that workflow to produce
`dev-build/` inside SpookyV4 without requiring the upstream compiled repository.
